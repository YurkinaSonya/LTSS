# Эксперимент по долгосрочным сбережениям

Репозиторий проекта экспериментального приложения для исследования стратегий долгосрочных сбережений.

В рамках проекта разрабатываются:

- **клиентская часть** — веб-приложение на Unity WebGL;
- **серверная часть** — backend для хранения данных, обработки игровой логики и подготовки аналитики.

Цель проекта — реализовать интерактивную среду, в которой участник проходит серию игровых периодов, принимает финансовые решения и взаимодействует с различными механиками эксперимента.

Сейчас репозиторий находится на начальном этапе настройки структуры проекта.

Дальше будет интересно.
